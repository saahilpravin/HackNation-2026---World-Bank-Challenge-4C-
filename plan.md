Goal:

We are making a mobile app that allows business owners to track their reviews (all languages/translations) and a small AI that can work in wifi-restricted areas and can analyze the reviews and give suggestions/feedback on how to improve.


Manager side

Dashboard:

The user should be able to look at their reviews with live text translations for foreign languages (button that directs you to the review page).
The user should be able to see their current, past, and future bookings
The user should be able to list their available times for booking/visitation and people capacity.

Review Page:

The user should be able to look at reviews in her native language (so live chat translation) and suggested responses (from ai assistant).
The user should be able to respond to the reviews with her own response or suggested response.

Insight/AI Assistant Page:

The user should be able to see the summarized points that the reviews share.
The user should be able to see suggestions/insight on what to improve
The user should be able to ask the ai questions (not the most important aspect of the project).
